# Project Images & Map Assets

[cite_start]This folder contains the high-resolution geospatial heatmaps generated in QGIS for the Melbourne Metropolitan Area public transport analysis[cite: 380, 445]. 

## Contents
* [cite_start]**`population-coverage.jpg`**: Visualizes the percentage of a suburb's resident population living within a 400-meter public transport catchment radius[cite: 445, 548].
* [cite_start]**`area-coverage.jpg`**: Visualizes the total geographic land area of each suburb covered by the 400-meter transit buffers[cite: 445, 548].
