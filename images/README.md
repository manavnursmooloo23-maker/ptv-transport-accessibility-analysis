# Project Images & Map Assets

This folder contains the high-resolution geospatial heatmaps generated in QGIS for the Melbourne Metropolitan Area public transport analysis.

## Contents
* **population-coverage.jpg**: Visualizes the percentage of a suburb's resident population living within a 400-meter public transport catchment radius.
* **area-coverage.jpg**: Visualizes the total geographic land area of each suburb covered by the 400-meter transit buffers.
