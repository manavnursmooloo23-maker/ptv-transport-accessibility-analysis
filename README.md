# 🚍 Public Transport Accessibility Analysis (PTV)

## 🔍 Overview
This project analyses public transport accessibility across Melbourne using SQL and spatial analysis techniques. It integrates transport, geographic, and population datasets to evaluate service coverage and identify underserved areas.

---

## 🎯 Objectives
- Analyse transport accessibility across suburbs  
- Combine transport and population datasets  
- Identify gaps in service coverage  

---

## 🛠 Tools & Technologies
- SQL (PostgreSQL / PostGIS)  
- QGIS  
- GTFS Data  
- ABS Data  

---

## ⚙️ Key Work
- Integrated multiple real-world datasets (transport + population)  
- Built SQL queries to compute accessibility metrics  
- Modelled 400m transport catchments  
- Visualised accessibility using GIS tools  

---

## 📊 Outcome
- Identified areas with limited transport access  
- Demonstrated spatial data analysis and database skills
